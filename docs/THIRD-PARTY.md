## Tabler Icons

- **What:** the icon sprite at `skins/default/icons.svg`
- **Version:** 3.48.0
- **Source:** https://tabler.io/icons, https://github.com/tabler/tabler-icons
- **Licence:** MIT

The sprite holds the upstream path data unmodified. The only change is that the
stroke attributes were moved from each file's `<svg>` element onto the matching
`<symbol>`, so one sprite can carry them all.
