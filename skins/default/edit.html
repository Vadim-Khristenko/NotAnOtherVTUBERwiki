{{ t("editor.cheatsheet") }}
  • # H1 … ###### H6, optional attrs at the end: ## Title {id="x" class="y"}
  • **bold**, *italic*, __italic__, ~~strike~~, ++underline++, ==mark==, ==red|hot== (red orange yellow green blue violet pink gray), ||spoiler||, `code`
  • H ~2~ O sub, E=mc ^2^ sup (spaces around markers)
  • [text](https://…) or [[slug|text]] for links
  • > quote, collapsible: >! Summary then > body; block: :::details Title … :::, pullquote: :::pullquote … :::
  • Alerts: > [!NOTE] / TIP / IMPORTANT / WARNING / CAUTION
  • - list, 1. numbered, task - [ ] todo, definition: Term then   : def
  • Footnote [^1] in text plus [^1]: note anywhere, definitions always collect at the bottom
  • [[toc]] alone in a paragraph becomes the page contents
  • ((Ctrl+C)) keyboard keys, :fire: :tada: :sparkles: emoji shortcodes (unknown codes stay literal)
  • Math: $E=mc^2$ inline, $$x+y$$ display, ```math block
  • Diagrams: ```mermaid / dot / plantuml … ``` (code text kept, SVG render comes with the worker)
  • Line break: two trailing spaces or <br>
  • Link to a heading: /page?jump_to=heading-id; force theme: ?theme=light
